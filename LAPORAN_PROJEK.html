PENGEMBANGAN SISTEM INFORMASI APOTEK BERBASIS LARAVEL 12 TERINTEGRASI POSTMAN DAN GITHUB
Mata Kuliah: Pemrograman Web & API Pengembang: Sayed Muhammad (sayedmuhammad27) Framework: Laravel 12.x Jadwal Presentasi: Kamis, 6 November 2026

BAB I: PENDAHULUAN & DASAR TEORI

Pengelolaan transaksi dan logistik pada sarana kefarmasian membutuhkan integrasi sistem yang terstruktur untuk mengantisipasi kesalahan pencatatan data pelanggan, ketiadaan arsip staf apoteker, dan resiko peredaran obat-obatan yang telah melewati masa kedaluwarsa. Sistem informasi apotek ini dibangun guna mengimplementasikan standar arsitektur web modern yang memadukan pola Model-View-Controller (MVC) pada framework Laravel 12 dengan standar layanan RESTful API dan integrasi pengujian terotomasi melalui Postman.

Dasar Teori Utama

  • Laravel Framework & MVC: Memisahkan representasi data (Model Eloquent), tampilan pengguna (Blade Views), dan alur logika sistem (Controllers) sehingga kode bersifat modular, dapat dipelihara, dan dapat diperluas.
  • RESTful API & JSON: Mengimplementasikan komunikasi data berbasis protokol HTTP (GET, POST, PUT, DELETE) menggunakan payload JSON yang ringan, berstandar industri, dan bebas status (stateless).
  • Postman API Platform: Menyediakan lingkungan pengujian endpoint, otomasi pengujian, dan ekspor koleksi (v2.1) sehingga mempermudah proses validasi kinerja API.
  • Basis Data Relasional & Portabilitas: Mengintegrasikan migrasi database Laravel yang kompatibel penuh dengan MySQL (XAMPP) maupun SQLite mandiri tanpa konfigurasi rumit.
  • Git & GitHub: Memastikan seluruh jejak pengembangan kode tersimpan secara terdesentralisasi dan dapat di-clone untuk demonstrasi langsung.

BAB II: PERANCANGAN & TAHAPAN PEMBUATAN APLIKASI

Sistem merangkul tiga entitas utama sebagaimana yang diinstruksikan dalam lembar lampiran:

  1. Pelanggan (pelanggans): Menyimpan id_pelanggan (kunci unik), nama, alamat, dan no_hp.
  2. Staf Apotek (staf_apoteks): Menyimpan id_staff (kunci unik), nama, alamat, tanggal_lahir (date picker), tempat_lahir, dan no_hp.
  3. Daftar Obat (obats): Menyimpan kode_obat (kunci unik), nama_obat, stock_obat (integer), dan tanggal_kadaluarsa (date picker).

Desain Antarmuka Ganda (Dual-Mode UI)

Untuk memenuhi instruksi tugas secara presisi, aplikasi dilengkapi dengan View Mode Switcher:

  • Mode Format Asli Lampiran (PDF): Mereplikasi layout formulir minimalis dengan garis batas hijau (#6b9e59) dan tombol simpan biru (#2563eb) persis seperti dokumen ujian/tugas dosen.
  • Mode Modern Interaktif: Mengadopsi estetika visual modern (aksen crimson-magenta dan kuning cerah, widget ringkasan statistik live, badge peringatan obat kedaluwarsa, dan konsol testing API langsung).

BAB IV: KESIMPULAN DAN SARAN

Kesimpulan

Seluruh kebutuhan tugas projek kelompok telah selesai dibangun 100%:

  1. Aplikasi berbasis Laravel 12 telah dilengkapi database relasional dan seeder untuk modul Pelanggan, Staf Apotek, dan Daftar Obat.
  2. Disediakan dua mode tampilan (Format PDF Asli & Desain Modern Visual).
  3. Tersedia konektivitas penuh ke Postman dengan file koleksi Apotek_API.postman_collection.json siap import.
  4. Projek telah ditautkan dan dikomit ke sistem kontrol versi Git untuk akun GitHub sayedmuhammad27.

BAB V: PANDUAN MENJALANKAN DARI GITHUB

# 1. Clone repositori
git clone https://github.com/sayedmuhammad27/apotek-laravel.git
cd apotek-laravel

# 2. Install pustaka dependensi
composer install

# 3. Setup environment & database
copy .env.example .env
php artisan key:generate
type nul > database\database.sqlite
php artisan migrate:fresh --seed

# 4. Jalankan web server (atau klik jalankan-aplikasi.bat)
php artisan serve
